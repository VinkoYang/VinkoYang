# Lab News Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an image-first "lab news" content stream to the site — a carousel on `/lab/`, an archive at `/lab/news/`, and a detail page per item — kept separate from the personal news timeline and the blog RSS feed.

**Architecture:** A new Jekyll collection `lab_news`, one Markdown file per item with `cover` / `gallery` front matter. Three render surfaces: an include (carousel), a page (archive), a layout (detail). Styling lives in one new SCSS partial; carousel behavior is a self-contained IIFE appended to the existing `assets/js/site.js`.

**Tech Stack:** Jekyll 4 + Liquid, SCSS (Bootstrap 5.3.3 partially imported), vanilla JS bundled by esbuild, Pillow for one-off image resizing.

## Global Constraints

- Source spec: `docs/superpowers/specs/2026-08-28-lab-news-design.md`.
- Working branch: `dev`. Do NOT merge to `source` — that branch triggers the GitHub Pages deploy.
- The repo has unrelated uncommitted changes (`_data/web/research.yml`, `assets/ref.bib`, `papers/yang2026seeing.pdf`). NEVER `git add -A` or `git add .` — stage only the exact files each task names.
- The browser loads `assets/js/site.min.js`, not `site.js`. Any change to `assets/js/site.js` MUST be followed by `npm run build:js`, and `site.min.js` MUST be committed in the same commit.
- Image paths in front matter are relative to `images/` — `cover: lab/news/.../x.jpg` renders as `/images/lab/news/.../x.jpg`. This matches the existing convention in `research.yml` and `equipment.yml`.
- Committed images must have a long edge of 1600px at JPEG quality 82. Never commit a multi-megabyte original.
- Colors, spacing, and radii come from the CSS custom properties in `_sass/base/_variables.scss` (`--space-4`, `--border-color`, `--bg-card`, `--text-muted`, `--radius-lg`, `--shadow-md`, `--accent`). Do not hardcode hex values — dark mode is driven entirely by these tokens.
- There is no test framework in this repo. The verification cycle for every task is `bundle exec jekyll build` followed by grepping the generated files under `_site/`.
- Verify a clean build with `bundle exec jekyll build 2>&1 | tail -5`. A successful run ends with a "done in N seconds" line.
- Commit message prefixes follow repo history: `feat:`, `fix:`, `content:`, `chore:`, `docs:`.
- Two changelogs, and they are not interchangeable — see the rules at the top of `CHANGELOG.md`. Work on `dev` appends a technical record (in Chinese) to the `## [待发布]` section of `CHANGELOG.md`. `_data/web/whatsnew.yml`, the version number, the `### [X.Y.Z]` history entry, and the git tag are all written at the `dev` → `source` release merge, which this plan does not perform. Do not bump a version anywhere.
- Every commit message ends with the trailer `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>`. Nesting `$(cat <<EOF ...)` inside `git commit -m` breaks in this shell, so write the message to a temp file and use `git commit -F <file>`.

**Spec deviation — read this before starting.** The spec says item files are named `YYYY-MM-DD-<slug>.md`. That is wrong for this permalink. Jekyll strips a date prefix from filenames only in `_posts`; for any other collection `:name` keeps the whole basename, so `2026-08-28-hms-seminar-saurbier.md` would publish at `/lab/news/2026-08-28-hms-seminar-saurbier/`. Item files therefore carry no date prefix, and ordering everywhere comes from the front matter `date:` field. Step 6 amends the spec to match.

- [ ] **Step 5: Append the carousel behavior to `assets/js/site.js`**

Append this at the very end of `assets/js/site.js`, after the final `})();` of the existing IIFE. It is a separate IIFE so the existing code is untouched.

```javascript

// =============================================================
// Lab news carousel — scroll-snap track, dot indicators, autoplay
// =============================================================

(function () {
  'use strict';

  var root = document.querySelector('[data-labnews-carousel]');
  if (!root) return;

  var track = root.querySelector('.labnews-track');
  var slides = root.querySelectorAll('.labnews-slide');
  var dots = root.querySelectorAll('.labnews-dot');
  if (!track || slides.length < 2) return;

  var INTERVAL = 6000;
  var reduceMotion = window.matchMedia('(prefers-reduced-motion: reduce)').matches;
  var current = 0;
  var timer = null;

  function setActiveDot() {
    dots.forEach(function (dot, i) {
      if (i === current) {
        dot.classList.add('is-active');
        dot.setAttribute('aria-current', 'true');
      } else {
        dot.classList.remove('is-active');
        dot.removeAttribute('aria-current');
      }
    });
  }

  function goTo(index) {
    current = (index + slides.length) % slides.length;
    track.scrollTo({
      left: slides[current].offsetLeft - track.offsetLeft,
      behavior: reduceMotion ? 'auto' : 'smooth'
    });
    setActiveDot();
  }

  function start() {
    if (reduceMotion || timer) return;
    timer = setInterval(function () { goTo(current + 1); }, INTERVAL);
  }

  function stop() {
    clearInterval(timer);
    timer = null;
  }

  dots.forEach(function (dot, i) {
    dot.addEventListener('click', function () {
      stop();
      goTo(i);
      start();
    });
  });

  // Keep the dots honest when the visitor swipes or scrolls the track directly.
  var scrollTimer;
  track.addEventListener('scroll', function () {
    clearTimeout(scrollTimer);
    scrollTimer = setTimeout(function () {
      var nearest = 0;
      var smallest = Infinity;
      slides.forEach(function (slide, i) {
        var distance = Math.abs(slide.offsetLeft - track.offsetLeft - track.scrollLeft);
        if (distance < smallest) { smallest = distance; nearest = i; }
      });
      current = nearest;
      setActiveDot();
    }, 100);
  });

  root.addEventListener('mouseenter', stop);
  root.addEventListener('mouseleave', start);
  root.addEventListener('focusin', stop);
  root.addEventListener('focusout', start);

  document.addEventListener('visibilitychange', function () {
    if (document.hidden) { stop(); } else { start(); }
  });

  setActiveDot();
  start();
})();
```
